# 升小數學面試練

面向 iPhone 嘅香港 **升小面試** 數學練習（zh-HK）。偏 **神小風格**：規律、比多少、圖畫應用、數感同口頭推理，而唔係死操紙筆計算。

## 模式

| 模式 | 說明 |
|------|------|
| **神小風格模擬** | 混合 8 題短輪；加重規律／比較／情境加減；可選每題約 45 秒計時 |
| **分類練習** | 揀一種題型慢慢練 |

## 題型（格式）

1. **數數** — 數物件
2. **認數字／配對** — 數字同數量
3. **比多少** — 邊堆多／少／一樣多
4. **簡單加減** — 圖畫／口頭應用（多數加、少減，約 10–12 以內）
5. **規律／找下一個** — ABAB、AAB、數量遞增、形狀循環
6. **圖形認識** — 圓／三角／方；搵唔同類
7. **排次序** — 由細到大撳次序排

答錯會溫柔顯示正確答案同簡短解釋。大按鈕方便細路撳。
