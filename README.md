# 升小數學面試練

面向 iPhone 嘅香港 **升小面試** 數學練習（zh-HK）。偏 **神小風格**：規律、比多少、圖畫應用、數感同口頭推理，而唔係死操紙筆計算。

## 模式

| 模式 | 說明 |
|------|------|
| **神小風格模擬** | 混合 8 題短輪；加重規律／比較／情境加減；可選計時 |
| **分類練習** | 揀一種題型慢慢練 |

## 難度（zh-HK）

| 難度 | 數字範圍 | 規律 | 計時壓力（模擬可選） |
|------|----------|------|----------------------|
| **基礎** | 細啲（約 2–5／加至約 8） | 簡單 ABAB、+1 遞增 | 每題約 60 秒 |
| **進階** | 面試常見（約至 10–12） | ABAB／AAB／形狀／數量 | 每題約 45 秒 |
| **神小挑戰** | 大啲（約至 15–18） | 加 ABC、+2 遞增等 | 每題約 30 秒 |

主畫面揀難度；會影響出題範圍、規律複雜度同計時秒數。

## 廣東話朗讀

- 題目旁有 **🔊 朗讀** 掣（Web Speech API）
- 聲線優先序：**zh-HK → yue → zh-TW → zh-CN**（跟 `voiceschanged` 更新）
- **iPhone**：必須喺同一個輕觸手勢入面呼叫 `speak()`；喇叭掣會同步朗讀。首次自動朗讀亦靠「開始」嗰下解鎖
- 可開 **自動廣東話朗讀題目**；亦可 **靜音**（關閉朗讀同答題音效）
- 唔支援／靜音／失敗會顯示提示
- 加減應用等文字題會一併讀出故事句

## 題型（格式）

1. **數數** — 數物件
2. **認數字／配對** — 數字同數量
3. **比多少** — 邊堆多／少／一樣多
4. **簡單加減** — 圖畫／口頭應用（多數加、少減）
5. **規律／找下一個** — ABAB、AAB、數量遞增、形狀循環等
6. **圖形認識** — 圓／三角／方；搵唔同類
7. **排次序** — 由細到大撳次序排

答錯會溫柔顯示正確答案同簡短解釋。大按鈕方便細路撳。
